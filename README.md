# SkyCast

A sleek, glass-styled desktop weather app for Windows.

## Features

- Real-time weather for any city worldwide — search, save favorites, auto-detects your location
- 10-day forecast, hourly breakdown with tap-to-preview, and a 12-hour temperature trend chart
- Humidity, wind, feels-like, air quality, UV index, pressure, dew point, visibility, and moon phase
- Next-hour rain/snow start-or-stop alerts
- Sunrise, sunset, and local time for the searched city
- Daily quotes (with a toggle for Bible verses)
- Sticky notes that persist between sessions
- Seasonal and festival themes (Christmas, Halloween, Songkran, and more)
- Modern "liquid glass" UI with smooth animations, resizable and draggable
- Built-in auto-updater — checks for new releases automatically
